# Narielly Santos — site autoral

Site estático responsivo em HTML, CSS e JavaScript, criado a partir da identidade editorial preto e branco aprovada.

## Abrir localmente
Abra `index.html` no navegador, ou sirva a pasta com `python -m http.server 8000` e acesse `http://localhost:8000`.

## Publicar
Envie os arquivos e pastas para um repositório do GitHub e ative **GitHub Pages** a partir da pasta raiz ou importe o repositório na **Vercel** como projeto estático. Não é necessário instalar bibliotecas ou compilar.

## Estrutura
- `index.html`: página inicial.
- `artigos/index.html`: listagem e categorias.
- `artigos/alem-do-agressor/index.html`: ensaio completo, com referências.
- `pesquisas/index.html`: projeto em desenvolvimento.
- `sobre/index.html`: apresentação da autora.
- `contato/index.html`: preparação de mensagem (sem endereço configurado).
- `assets/style.css`, `assets/app.js`: estilos e interações.
- `assets/*.webp`: imagens editoriais extraídas da referência visual aprovada, não representativas da autora.

## Personalização recomendada
Substitua `assets/hero-portrait.webp` por um retrato autoral quando desejar. Configure o endereço público de contato antes de divulgar a página de contato. Acrescente os próximos artigos no índice e na busca em `assets/app.js`.

**Observação:** o ensaio está rotulado como divulgação científica, não como artigo revisado por pares. Confira as fontes e a versão final do texto antes de torná-lo público.
